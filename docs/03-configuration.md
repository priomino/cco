# Configuration reference

| Key | Where | Default | Allowed values | Effect |
|---|---|---|---|---|
| `COMPOSE_PROJECT_NAME` | `.env` | `cco` | any compose-safe name | Prefix for all containers, networks and volumes; keeps the stack separate from other workloads. |
| `CCO_ENGINE_PROFILE` | `.env` | `cpu` | `cpu`, `igpu` | Chooses the engine compose profile. |
| `CCO_DIAG_PORT` | `.env` | `18400` | free TCP port | Optional diagnostic port, published on 127.0.0.1 only. |
| `engine.backend` | `config.yaml` | `unsloth` | `unsloth` (future: `dmr`) | Selects the engine backend behind the stable proxy contract. |
| `engine.profile` | `config.yaml` | `cpu` | `cpu`, `igpu` | Same as `CCO_ENGINE_PROFILE`; the `.env` value wins if both are set (verify when implemented). |
| `engine.diagnostic_port` | `config.yaml` | `18400` | free TCP port | Same as `CCO_DIAG_PORT`. |

Version pins (Unsloth, Claude Code, model and quant) are added when those components are introduced.

## Engine build settings

| Key | Where | Default | Allowed values | Effect |
|---|---|---|---|---|
| `CCO_UNSLOTH_VERSION` | `.env` | `latest` | `latest` or an exact `unsloth` release | `latest` tracks the newest release; an exact version pins it (constraints file). |
| `CCO_UNSLOTH_INSTALLER_SHA256` | `.env` | empty | empty or 64 hex characters | When set, the build fails if `install.sh` no longer matches. Get the current value with `build-engine.ps1 -ShowInstallerSha`. |
| `CCO_ENGINE_PYTHON` | `.env` | `3.12` | Python version supported by the installer | Python used inside the engine image. |
| `CCO_ENGINE_IMAGE` | `.env` | `cco-engine` | image name | Image name; tags are `<variant>` (floating) and `<version>-<variant>` (snapshot). |

`CCO_ENGINE_PROFILE=cpu` builds the `cpu` variant; `igpu` builds the `vulkan` variant.

## Model settings

| Key | Where | Default | Allowed values | Effect |
|---|---|---|---|---|
| `CCO_MODEL_REPO` | `.env` | `bartowski/Qwen2.5-7B-Instruct-GGUF` | Hugging Face repo with GGUF files | Source of the model download. |
| `CCO_MODEL_FILE` | `.env` | `Qwen2.5-7B-Instruct-Q4_K_M.gguf` | a file name in that repo | Quant and file to download (Q4_K_M is about 4.4 GiB). |
| `CCO_MODEL_SHA256` | `.env` | empty | empty or 64 hex characters | Expected checksum; if empty, the checksum published by Hugging Face is used. A mismatch fails the download. |

The model is stored in the Docker volume `cco_models` (mounted at `/models`). Download with `scripts\windows\download-model.ps1`.

## Engine runtime settings

| Key | Where | Default | Allowed values | Effect |
|---|---|---|---|---|
| `CCO_ENGINE_CONTEXT` | `.env` | `32768` | integer up to the model's limit | Context window passed to `unsloth run --context-length`; the KV cache grows with it (about 1.8 GiB at 32768 for this model, estimate). |
| `CCO_STUDIO_PASSWORD` | `.env` | generated | any string | Initial admin password for the engine (`UNSLOTH_STUDIO_PASSWORD`); generated by the scripts, never commit. |

## Claude Code settings

| Key | Where | Default | Allowed values | Effect |
|---|---|---|---|---|
| `CCO_CLAUDE_VERSION` | `.env` | `latest` | `latest` or a version accepted by the official installer | Claude Code version built into the image (`build-claude.ps1`). |
| `CCO_CLAUDE_IMAGE` | `.env` | `cco-claude` | image name | Image name; tags `cli` (floating) and `<version>` (snapshot). |
| `CCO_CLAUDE_MODE` | `.env` | `bare` | `bare`, `lean`, `full` | Tool set and prompt size, see architecture D27 and D28; `claude.ps1 -Mode` overrides it per run. |
| (fixed settings) | `docker/claude/claude.env`, `docker/claude/mode-<mode>.env` | see files | `KEY=VALUE` lines | Environment passed to Claude Code (timeouts, telemetry off, context size, mode switches). |

## General settings

| Key | Where | Default | Allowed values | Effect |
|---|---|---|---|---|
| `COMPOSE_PROJECT_NAME` | `.env` | `cco` | lowercase letters, digits, `-`, `_` | Prefix for compose resources; keep it unless you know why you change it. |
| `CCO_ENGINE_PROFILE` | `.env` | `cpu` | `cpu` (`igpu` is not available in v1.0) | Engine variant to build and run. |
| `CCO_ENGINE_TEMPERATURE` | `.env` | `0.7` | 0 to 2 | Sampling temperature pinned on the engine for requests that omit it (`unsloth run --temperature`). |
| `CCO_DIAG_PORT` | `.env` | `18400` | port number | Reserved for a future host-access option; not used in v1.0. |
